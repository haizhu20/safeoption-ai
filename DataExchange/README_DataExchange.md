# DataExchange Rules

This folder is the public data exchange area for external collaboration teams.

Current collaboration teams:

* Xiaomi Team
* Orion Team

## Folder Structure

Incoming/

* New uploaded files
* Unreviewed packages

Reviewed/

* Files reviewed by the Orion team

Approved/

* Final approved versions

Archive/

* Old or deprecated versions

---

## File Naming Rules

Please use the following naming format:

YYYYMMDD_Team_Project_Version_Description.zip

Examples:

20260609_XiaomiTeam_SafeOptionAI_V01_UIFixPackage.zip

20260609_XiaomiTeam_SafeOptionAI_V02_DeploymentPatch.zip

---

## Upload Rules

1. Do not overwrite existing files.
2. Always upload a new version with a new filename.
3. Large packages should be compressed as ZIP files.
4. Include screenshots or README files when possible.
5. Upload all new files into Incoming/.

---

## Review Workflow

Incoming → Reviewed → Approved → Archive
